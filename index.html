1. 電腦概論：硬體、數字、記憶體

最常考的是 CPU 內部元件分工、記憶體速度階層與數字系統換算。

五大單元與 CPU

  • 五大單元：輸入、輸出、記憶、算術邏輯（ALU）、控制（CU）。指揮協調＝控制單元；實際運算＝ALU。
  • CPU 內含：控制單元、ALU、暫存器、快取記憶體。
  • 程式計數器（PC）存「下一個」指令位址，屬控制單元；指令暫存器（IR）存「目前」指令。
  • 機器週期：擷取 → 解碼 → 執行 → 寫回（沒有「編碼」「重載」）。指令週期（I-cycle）＝提取、解碼、取運算元位址；執行週期（E-cycle）＝執行、存回。
  • 定址模式的用途＝運算元提取。
  • 匯流排三種：資料（雙向）、位址（單向，CPU 只輸出）、控制。定址空間只看位址線：n 條 → 2n Bytes。
  • 雙核心＝兩個實體核心平行運算，耗電不是 2 倍；Hyper-Threading＝單核模擬兩個邏輯處理器。
  • 中斷：硬體中斷是非同步事件；高優先權中斷可打斷低優先權（巢狀中斷）。
  • CPU 只執行機器語言；時脈越高（同架構）越快。

記憶體與儲存

  • 速度：暫存器 ＞ 快取 ＞ 主記憶體（RAM）＞ SSD ＞ 硬碟 ＞ 光碟。
  • RAM 揮發性；SRAM（正反器，快、貴、做快取）vs DRAM（電容，需刷新、密度高、做主記憶體）。題庫認定 DRAM 耗電較少。
  • ROM 非揮發，存 BIOS/UEFI，開機執行 POST；新版 BIOS 在快閃 ROM，可更新。EPROM＝可消除可規劃 ROM。
  • 快取容量遠小於主記憶體；Disk Cache＝用記憶體加速磁碟。
  • 虛擬記憶體＝硬碟模擬記憶體，可執行比實體記憶體大的程式；虛擬磁碟（RAM Disk）＝記憶體模擬磁碟，兩者相反。
  • 硬碟存取時間＝搜尋時間 ＋ 旋轉延遲 ＋ 資料傳輸時間；最小存取單位是磁區。磁柱 ＞ 磁軌 ＞ 叢集 ＞ 磁區。
  • SSD 用快閃記憶體、無機械旋轉；HDD 單顆容量最大。SATA＝序列、可熱插拔；IDE＝並列。
  • 光碟容量：CD 約 700MB；DVD 4.7GB（單層）/ 8.5GB（雙層），650nm 紅光；BD 25GB / 50GB，405nm 藍光。DVD 燒錄機不能燒 BD。DVD-RAM、-RW、+RW 可重複寫。

數字系統與編碼

  • 有號 8 位元範圍 −128～+127；無號 0～255。
  • 十進位小數不一定能用有限位二進位表示（0.1、0.815 會有誤差；0.5、0.625、0.5625 可精確）。
  • ASCII 順序：數字（48–57）＜ 大寫（65–90）＜ 小寫（97–122）。「F」＝70＝01000110。
  • Unicode 碼位有限（到 U+10FFFF），與 ASCII 相容。Big-5 中文字＝2 Bytes。
  • 錯誤偵測：同位元、CRC、Checksum 只能偵錯；漢明碼可更正。奇同位＝1 的個數為奇數。
  • 單位：K M G T P E Z Y，每級 210（1TB＝240 Bytes）。大數據 3V＝Volume、Velocity、Variety。

布林代數

  • 狄摩根：(A+B)'＝A'B'；(AB)'＝A'+B'。
  • A(A'+B)＝AB；A+A'B'＝A+B'；X'Y+XY'＝X⊕Y。
  • XOR：相同為 0、不同為 1。判斷同網段用 IP AND 子網路遮罩。

周邊與介面

  • 輸入：鍵盤、滑鼠、麥克風、掃描器、光筆、數位相機；輸出：螢幕、印表機、喇叭、繪圖機。
  • 螢幕更新率單位 Hz；解析度 640×480＝水平×垂直。
  • 點陣圖放大會失真；向量圖不會。灰階＝不同亮度的灰；HDMI 傳數位影音、支援熱插拔；USB 隨插即用。

2. 網路與通訊

網路題最集中在 OSI 分層、埠號、IP 分級與網路設備對應的層級。

  • TCP/IP 四層：應用、傳輸、網際網路、網路存取。
  • 中繼器＝放大整形訊號；集線器＝廣播到所有埠；橋接器＝連接兩個同類型 LAN；路由器＝建路由表選路徑、可取代橋接器、預設不轉送廣播。
  • 交換器每個埠是獨立碰撞網域；分割網路會增加網域數、降低碰撞。儲存轉送＝先檢查 CRC，延遲較高但能濾掉錯誤訊框。

TCP、UDP 與常用埠號

  • TCP：連接導向、三向交握、可靠、流量與壅塞控制；不負責加密。UDP：無連接、快。
  • 使用 TCP：HTTP、FTP、SMTP、Telnet、SSH。使用 UDP：DHCP、TFTP、SNMP、DNS 查詢。

IP 位址

  • IPv4＝32 位元（每段 0–255，256 不合法）；IPv6＝128 位元，支援 Unicast/Multicast/Anycast、內建 IPSec、自動設定。
  • 分級看第一段：A 1–126、B 128–191、C 192–223、D 224–239（群播）。預設遮罩 A 255.0.0.0。
  • 私有 IP：10.0.0.0/8、172.16.0.0–172.31.255.255、192.168.0.0/16。
  • DHCP 自動配發 IP、遮罩、閘道、DNS；動態 IP 連線時才取得。NAT／寬頻分享器讓多台共用公有 IP。
  • DNS 正向解析＝名稱查 IP；反向解析＝IP 查名稱。ARP＝IP 轉 MAC。
  • ICMP 封裝在 IP 封包內、回報錯誤；ping 測連通、tracert/traceroute 追路徑、ipconfig/ifconfig 看設定、netstat 看連線統計。

拓樸、媒介與傳輸

  • 單工（廣播）、半雙工（對講機）、全雙工（電話）。
  • 星狀：中央控制，中央壞全網停；匯流排：一條主幹；環狀：節點數有限制。
  • 頻寬：光纖 ＞ 同軸電纜 ＞ 雙絞線。光纖可傳類比與數位、不受電磁干擾、衰減小、常用於骨幹。
  • 分封交換＝存轉式、封包有長度上限；電路交換先建專線。ATM 以 53 Bytes Cell 傳輸、可相容不同速率。
  • 乙太網路 CSMA/CD（碰撞偵測，隨機 Backoff）；Wi-Fi 802.11 用 CSMA/CA（碰撞避免）、半雙工。
  • 藍牙 2.4GHz、約 10m／100m，藍牙 4.0 約 60m（200 英呎）；NFC 約 10 公分，用於行動支付；紅外線需直線對準。
  • Modem＝數位↔類比調變解調；WDS 讓 AP 無線互連（同頻道、同加密）。
  • 電子郵件：寄信 SMTP；收信 POP3／IMAP。密件副本收件者看得到正本與副本名單。
  • WWW＝Client/Server、HTTP；伺服器端程式 PHP、ASP、JSP、CGI；用戶端 JavaScript、VBScript、Java Applet。Proxy 快取網頁加速瀏覽；RSS 用 XML 推送更新。

3. 資料庫、資料結構、程式與新興科技

資料庫與 SQL

  • 資料庫模型：階層、網路、關聯、物件導向（星狀是網路拓樸，不是資料庫模型）。ER 模型＝概念模型。
  • 關聯式以「內容」查詢；主鍵必須唯一且不可 NULL，外來鍵可重複。DBMS 目的是「減少」重複。
  • 正規化消除重複與異常：1NF → 2NF（非主鍵屬性完全功能相依主鍵）→ 3NF。
  • SQL 三類：DDL（CREATE/ALTER/DROP）、DML（SELECT/INSERT/UPDATE/DELETE）、DCL（GRANT/REVOKE）。
  • INSERT INTO T (a,b) VALUES (1,2); 不能漏 VALUES。DELETE 沒加 WHERE＝刪光全部資料（結構保留）；DROP TABLE 刪整表。
  • ORDER BY … ASC 遞增（預設）、DESC 遞減。部分字串比對用 LIKE '台中市%'，不是 =。
  • LEFT JOIN 保留左表每筆（至少出現一次）；CROSS JOIN 筆數 N×M、欄位 X+Y。
  • 關聯代數：選擇 σ 挑列（WHERE）；投影 π 挑欄（SELECT 欄位）。
  • 交易 ACID：Atomicity 不可分割、Consistency、Isolation、Durability。
  • 資料倉儲：主題導向、整合、時間變動、「非揮發」；模型為星狀、雪花、星座。資料探勘做在資料倉儲上。
  • View＝虛擬表格，可合併多表、隱藏欄位。

資料結構與演算法

  • 堆疊 Stack＝LIFO：副程式返回位址、遞迴、參數傳遞；滿了再 push＝溢位。
  • 佇列 Queue＝FIFO：鍵盤緩衝、列印、工作排程。
  • 排序：快速排序平均 O(n log n) 最快；氣泡、選擇、插入 O(n²)。氣泡排序可大到小。資料太大放不進主記憶體＝外部排序。
  • 區段搜尋只要求區段之間有序，區段內不必排序。

程式語言與系統程式

  • 編譯器整份翻成目的碼，只能抓語法錯誤；直譯器一行翻一行執行；組譯器處理組合語言（低階）。
  • 連結器產生執行檔；載入程式（Loader）四功能：配置、連結、重定位、載入（沒有緊結）。
  • 結構化程式：循序、選擇、重複三結構；單一入口、單一出口；避免 GO TO；缺點是較占記憶體。
  • Java 編成 Bytecode，由 JVM 執行而跨平台；UML 是塑模語言，不是網頁語言。
  • C/C++：main 為進入點；區塊用 { }；常數不可改值；關鍵字小寫（while 不是 While）；do…while 至少執行一次。

作業系統觀念

  • OS 功能：行程、記憶體、I/O、檔案管理；排序、輸入法不是 OS 功能。
  • 排程：FIFO、SJF（平均等待最短，會飢餓）、RR（時間配額、處理器共享）；Race Condition 不是排程法。
  • 分時系統一定是多程式系統，反之不一定；多工不一定需要平行處理。
  • 批次處理：銀行計息、薪資；分時處理：多使用者輪流用 CPU。

新興科技

  • 物聯網三層：感知層（RFID、感測器、三軸加速器）、網路層（通訊、雲端運算、NGN）、應用層（智慧交通、醫療）。IBM「智慧地球」＝物聯網雛型。
  • RFID 標籤：Active、Passive、Semi-Passive；NFC 用於電子支付。
  • Hadoop：HDFS 分散儲存、一次寫入多次讀取；MapReduce 分派再彙整；Hive 類 SQL；Streaming 用外部腳本。
  • Spark：In-Memory 運算、核心為 RDD；MLlib 機器學習。NoSQL：Key-Value、免固定綱要、水平擴充、非同步複製；BigTable 是 NoSQL。R 是開源統計語言。
  • Web 1.0 單向、2.0 互動、3.0 語意網。PayPal＝第三方支付。雲端 IaaS／PaaS／SaaS。
  • 資訊系統轉換：平行式最安全、成本最高；直接、引導式、階段式。

Word

  • 選取區按一下＝一行、兩下＝一段、三下＝整份文件。
  • 不同頁碼格式、頁首頁尾、紙張方向要「分節」；設定欄數會自動插入分節符號。
  • 每頁相同位置的圖案放在頁首/頁尾；花邊在「頁面框線」；刪除裁剪區域用「壓縮圖片」。
  • 防寫密碼仍可唯讀開啟並複製；範本可再存成新範本（.dotx）；縮放比例不影響列印。
  • 表格轉文字框線會消失；儲存格網底只能單色＋圖樣（不能圖片、漸層、材質）。
  • 合併列印的 Excel 資料來源一次只能一個工作表。萬用字元取代時 ( ) 分組、\2 代表第 2 組。
  • 並列文字字型縮為一半；圍繞字元一次一個中文字；標號用 {SEQ}，用於圖、表、方程式。
  • 避頭字元：問號、冒號、逗號、句號、右括號等不放行首。

Excel

  • 參照運算子：「:」範圍、「,」聯集、空格＝交集；& 串接文字（結果為文字，日期格式無效）。
  • 相對位址複製時會變；$ 固定。條件式格式每列判斷 E 欄：=$E2<60。
  • 錯誤值：##### 欄寬不足（不是公式錯）；#DIV/0!、#N/A、#NAME?、#REF!、#VALUE!。
  • RAND() 亂數、ROUND() 四捨五入、INT() 取整；格式只改顯示，計算用真實值。
  • MAX／MIN／COUNT 以範圍參照時忽略文字，全無數值回傳 0。偶數列：=MOD(ROW(),2)=0。
  • 民國年輸入 r109/11/10；會計專用格式貨幣符號靠左，負號在前（-$ 0.96）。自訂格式 # 只顯示有效位數，_ 保留一字元空白。
  • 保護工作表＝內容、物件、分析藍本；保護活頁簿＝結構與視窗（不管儲存格）。
  • 目標搜尋＝反推「一個」變數；規劃求解可多變數。小計前必須先排序。
  • 進階篩選準則可用函數；同列 AND、不同列 OR。圓形圖只能一個數列。
  • 列印：開檔直接按列印只印使用中工作表；整本活頁簿要在「列印內容」選擇；起始頁碼在「版面設定 → 頁面」。合併活頁簿無法復原。

PowerPoint

  • 副檔名：.pptx 簡報、.potx 範本、.ppsx 播放檔（不開 PowerPoint 即可播放）；.dotx 是 Word 範本。
  • 每張投影片換頁時間可各自設定（排練計時）；動畫開始：按一下、與前動畫同時、接續前動畫。
  • 大綱模式只顯示版面配置區文字；投影片編號在「投影片母片」調整；多張圖一次插入用「相簿」。
  • 封裝成光碟也可複製到資料夾。不能插入可運作的資料庫表單。

Access 與檔案格式

  • Access 是關聯式資料庫；強迫參考完整性防止刪除仍有子記錄的主記錄。
  • 主索引鍵不可重複；備忘、OLE、附件欄位不能當主索引鍵。標籤是非結合控制項。
  • 交叉資料表查詢需搭配合計；萬用字元 * 任意多字、? 恰一字。Word 檔不能匯入 Access。
  • OOXML（.docx/.xlsx/.pptx）＝ISO/IEC 29500；ODF（.odt/.ods/.odp）＝ISO/IEC 26300；.doc 是二進位格式。

影像處理

  • Photoshop 以點陣為主、原生 PSD 保留圖層；Illustrator 以向量為主（.ai）。
  • 色彩三屬性：色相、飽和度、亮度。網頁圖檔：GIF、JPEG、PNG。
  • 照片大小＝(吋×dpi)²×3 Bytes（全彩 24 位元），見第 7 節。

6. 資訊安全

資安題多是常識判斷，抓住「題庫標準答案的原則」就能拿分：密碼不共用、備份分地存放、防火牆不等於防毒。

核心觀念

  • 資安三要素 CIA：機密性（Confidentiality）、完整性（Integrity）、可用性（Availability）；另有可靠性、身分識別（Authentication）、不可否認性。
  • 弱點（Vulnerability）是系統本身的瑕疵；最大的弱點常是「人」（人性弱點、社交工程）。
  • 風險處理四策略：規避、降低、轉移、接受。資安管理三要素 People、Process、Technology。

加密與認證

  • 對稱式（DES、AES）：加解密同一把金鑰，需安全傳送金鑰。非對稱式（RSA）：公鑰公開、私鑰保密，兩把不能互推。
  • 數位簽章：用「傳送者私鑰」簽、對方用其公鑰驗，確認來源、完整、不可否認。加密給某人則用「對方公鑰」。
  • SSL/TLS（https）加密傳輸；數位浮水印用於版權保護；VPN 建立加密通道。
  • 生物辨識：指紋、視網膜比對。密碼要長、不常見、定期更換；禁止不同使用者用同密碼；不由管理者統一保管使用者密碼。

防護設備與作法

  • 防火牆：依規則過濾封包、預設拒絕規則外封包；不能防所有病毒、不能擋內部對外攻擊、不負責用戶身分管理；也可用於廣域網路。
  • IDS 偵測警示；IPS 偵測後主動阻擋。阻擋 DoS 靠 IDPS，不是多加路由器。
  • 用 SSH 取代 Telnet（明文）；伺服器只裝必要模組、裝最新修補程式。
  • 備份：備份要加密、異地存放，不和原檔放同一磁碟；遞增備份只備上次以來變動。RAID 1（鏡像）／RAID 10 有容錯。遠端複本、不斷電系統、備援系統屬可用性。
  • 實體安全：事前要有嚇阻效果；員工離職應在通知前先收回權限。
  • 智慧財產權：商標、專利、著作權。
